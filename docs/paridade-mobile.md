# Paridade mobile × web

Matriz da FE-23: cada tela e ação do app Flutter ([`lucroai_mobile`](https://github.com/GrupoDoisENG/lucroai_mobile)) em uso por `lib/core/presentation/pages/main_screen.dart`, a rota web que a substitui e as diferenças intencionais. O detalhe de cada diferença está em [business-rules.md](business-rules.md#diferenças-intencionais-em-relação-ao-mobile) e nas [lacunas do backend](api-integration.md#lacunas-do-backend).

**Resultado: nenhuma funcionalidade do mobile ficou sem equivalente na web.**

Valem para todas as telas: textos com acentuação correta e, desde a FE-57, na linguagem de cozinha da marca (o nome de cada tela na web está na coluna "Web"; as rotas não mudaram), busca que ignora acentos, campos numéricos no formato brasileiro (`1.234,56`), erro da API num `Alert` dentro do formulário (e não num SnackBar), e carregamento, vazio e erro com "Tentar de novo".
